# webtest

 WebTest：在线题库练习与考试系统

这是一个完全在浏览器端运行的 Web 应用，旨在提供一个创建、练习和模拟考试的平台。它使用纯 HTML、Tailwind CSS 和原生 JavaScript 构建

## 主要功能

### 用户功能

- **练习模式**：可选择进行阅读题或计算题的专项限时练习。
- **考试模式**：模拟完整的考试流程，包含限时的阅读和计算两个部分。
- **错题回顾**：所有答错的题目都会被自动收录，方便用户集中复盘。
- **多语言界面**：支持中文、日文、英文三种语言。
- **外观切换**：支持浅色、深色模式，并可跟随系统设置自动切换。
